## Purpose

定义 AgentCore 运行时安全闭环的行为契约，覆盖 Human-in-the-Loop 审批的完整运行时执行链与文件沙箱的真实隔离执行，确保配置的安全策略真实生效而非占位。

## ADDED Requirements

### Requirement: HITL 审批运行时闭环
系统 MUST 在配置了 `interrupt_on` 策略的工具调用触发时，执行完整的人工审批闭环：暂停执行、呈现审批请求、接收决策、按决策继续或终止。

#### Scenario: 危险操作暂停等待审批
- **WHEN** Agent 触发一个被配置为需要审批的工具调用
- **THEN** 运行时 SHALL 在工具执行前暂停，并通过审批通道呈现该请求（含操作类型、参数、原因）。

#### Scenario: 批准后继续执行
- **WHEN** 审批人对暂停的调用选择"批准"
- **THEN** Agent SHALL 使用原参数继续执行该工具调用。

#### Scenario: 编辑参数后批准
- **WHEN** 审批人对暂停的调用选择"编辑参数后批准"
- **THEN** Agent SHALL 使用编辑后的参数执行该工具调用。

#### Scenario: 拒绝后终止
- **WHEN** 审批人对暂停的调用选择"拒绝"
- **THEN** Agent SHALL 终止该工具调用并据此继续其后续流程。

#### Scenario: 决策可审计
- **WHEN** 审批人做出决策
- **THEN** 系统 SHALL 在不可变审计记录中保存操作者、时间戳、决策类型与最终工具入参。

#### Scenario: 无审批不静默超时
- **WHEN** 审批请求被呈现但未及时处理
- **THEN** 系统 SHALL 明确呈现等待状态而非静默超时，且不丢弃该审批请求。

### Requirement: 文件沙箱真实隔离执行
系统 MUST 对沙箱化执行提供真实的隔离运行环境，而非降级占位，使危险代码在受限环境中运行。

#### Scenario: 沙箱内执行代码
- **WHEN** Agent 被配置为沙箱执行模式并触发代码执行
- **THEN** 该代码 SHALL 在隔离的沙箱环境中运行，与宿主文件系统及网络隔离。

#### Scenario: 沙箱环境不可用时明确失败
- **WHEN** 配置了沙箱执行但沙箱后端不可用
- **THEN** 系统 SHALL 明确报告能力不可用，而非静默降级为宿主执行。
